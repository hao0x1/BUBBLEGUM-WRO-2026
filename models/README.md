# CAD and fabrication models

- `Ackermann Chassis CLEAN Named Assembly.f3z` — the editable Fusion assembly
  of the chassis. Stored with Git LFS, so clone with `git lfs install` first.
- Printable exports and STL files land here once the parts are frozen and the
  print settings that survived testing are recorded.
- For every external model we adapt, we record the units, material, revision,
  source and license before it goes in.

The assembly has not been physically verified yet. Verification needs the
ready-to-run envelope with steering straight, full-left and full-right, plus
mass, wheelbase, track width, tyre size and the mechanically coupled driving
axle.
