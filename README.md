# BUBBLEGUM WRO Future Engineers 2026

Competition source and field tools for our ESP32-S3 / Lushan-Pi K230 car.

## Current status

Repository initialized. We are bringing up the ESP32-S3 controller, its sensors, and the Lushan-Pi K230 camera board.

## Repository layout

- `src/ESP32-S3-N16R8`: PlatformIO controller firmware (planned).
- `src/LCKFB-Lushan-Pi-K230`: camera program (planned).
- `models`, `schemes`, `other`: CAD, wiring drawings and component records.
- `local/`: private logs and experiments, excluded from Git.
